# Smart Body Core — WordPress plugin

Makes WordPress the source of truth for **gyms, cities, sports and gym registrations** of Smart Body (بدن هوشمند). ACF is **not** required.

## Install
1. Zip the `smart-body-core` folder and upload it via *Plugins → Add New → Upload*, or copy it to `wp-content/plugins/`.
2. Activate **Smart Body Core**. The **بدن هوشمند** menu appears in wp-admin.
3. Optional: go to *بدن هوشمند → اتصال و ابزارها* and click **وارد کردن داده نمونه** to import the same sample cities, sports and gyms the frontend uses.
4. Permalinks must not be "Plain" (REST lives under `/wp-json/`).

## Connect the Smart Body backend
1. In *Users → Profile → Application Passwords*, create a password for an **Editor or Administrator** user.
2. Set these in `backend/.env` (or production secrets):
```
WP_BASE_URL=https://your-site.ir
WP_USERNAME=editor-user
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx xxxx xxxx
```
3. Restart the backend. `GET /api/integrations/wordpress/status` shows `reachable: true`, and the frontend is now served from WordPress.
   If WordPress is not reachable, the backend automatically falls back to the built-in sample gyms (the `X-Data-Source` response header tells you which one was used).

## Data model
| Smart Body field | WordPress |
|---|---|
| name (gym_name) | post title |
| slug | post slug (`post_name`) |
| description | excerpt, otherwise content |
| image (featured_image) | featured image, otherwise `image_url` meta |
| city | taxonomy `city` (term meta: `province`) |
| sports | taxonomy `sport` (term meta: `image_url`, `featured`, `order`) |
| address, neighborhood, street, phone, manager_name | post meta |
| rating (0–5), is_featured, badge | post meta |
| landing_page_requested, landing_page_status (`none`/`requested`/`in_progress`/`done`), landing_page_url | post meta |
| source (`registration`/`sample`), external_id | post meta (read-only) |
| approval status | post status: `pending` → `publish` (approved) / `draft` / `trash` |

## REST API — `/wp-json/smartbody/v1`
| Method | Route | Auth | Notes |
|---|---|---|---|
| GET | `/status` | public | plugin version + gym counts |
| GET | `/cities` | public | `[{slug, name, province}]` |
| GET | `/sports` | public | `[{slug, name, image, featured}]`, sorted by `order` |
| GET | `/gyms` | public | `city` (name or slug), `q` (street/neighborhood/area), `sport` (slug), `featured`, `limit`; published only, sorted by rating |
| GET | `/gyms/{slug}` | public | 404 `sb_not_found` |
| GET | `/registrations` | App Password | pending and draft gyms |
| POST | `/registrations` | App Password | creates a **pending** gym; idempotent on `externalId` |

POST body: `{externalId, gymName, managerName, phone, city, neighborhood, address, sports[], landingPageRequested, mediaId?, imageUrl?}`.
The backend first uploads the image to `/wp-json/wp/v2/media` and sends the `mediaId`.

## Admin workflow
- **در انتظار تأیید**: new registrations (pending). The **تأیید و انتشار** row action publishes them.
- **درخواست‌های لندینگ پیج**: gyms whose `landing_page_status` is `requested`. Set the status to *در حال طراحی* or *تحویل شده* and fill in `landing_page_url` in the **اطلاعات باشگاه** box.
- **شهرها / رشته‌های ورزشی**: manage the taxonomies. For sports, set the image, "show in homepage strip" and the display order.
